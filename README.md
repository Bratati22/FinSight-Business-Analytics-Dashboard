# 💳 FinSight – Financial Transaction Analytics Dashboard

An interactive **Business Analytics dashboard** built in **Power BI** to analyze financial transactions, customer segments, transaction trends, taxes, fees, and Year-over-Year (YoY) business performance.

> A portfolio project demonstrating Business Analyst and Data Analyst skills using Power BI, DAX, Power Query, and data modeling.

## 🎯 Business Problem

Banks and financial institutions process thousands of transactions every day. Business stakeholders need a centralized dashboard to monitor transaction performance, customer behavior, regional trends, and revenue-related KPIs.

**FinSight** provides a real-time analytical view of transaction data to support business decision-making.

---

## 📌 Key KPIs

| KPI                       | Description                               |
| ------------------------- | ----------------------------------------- |
| Total Transaction Amount  | Total value of all financial transactions |
| Total Transactions        | Number of completed transactions          |
| Average Transaction Value | Average amount per transaction            |
| Total Fees                | Total transaction fees collected          |
| Total Tax                 | Total taxes generated                     |
| YoY Growth %              | Year-over-Year comparison using DAX       |

## 📊 Business Insights Included
